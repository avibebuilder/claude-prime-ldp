### Prerequisites

The visual feedback loop relies on Gemini for UI quality scoring (Claude's built-in vision isn't reliable enough for pixel-level feedback). Before running, create:

```
.claude/media-processor/.env
```

```env
GEMINI_API_KEY=your-gemini-api-key
```

## What Got Built

A full marketing landing page for [Claude Prime](https://github.com/avibebuilder/claude-prime) featuring:

- Retro terminal/CRT aesthetic with gold accent theming
- Hero section with animated terminal and install command
- Features grid showcasing capabilities
- How-it-works walkthrough
- Interactive elements: typing cursor, copy buttons, floating CTA, scroll-to-top

**Tech stack:** Next.js 16, React 19, TypeScript, Tailwind CSS v4, JetBrains Mono
